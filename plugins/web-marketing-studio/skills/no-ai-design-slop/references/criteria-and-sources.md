# Criteria and sources

## Standards

Use [WCAG 2.2](https://www.w3.org/TR/WCAG22/) for testable accessibility requirements. Particularly relevant criteria include information and relationships, meaningful sequence, contrast, reflow, content on hover or focus, keyboard access, focus visible and not obscured, target size, labels, and name/role/value.

Use [WAI: Page Structure](https://www.w3.org/WAI/tutorials/page-structure/) for semantic page organization and [MDN: `prefers-reduced-motion`](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion) for the platform preference mechanism.

## Heuristics

The removal test, decorative-stacking test, coherence test, one-focal-point guidance, and named pattern clusters are editorial design heuristics. They are not accessibility conformance rules and should be justified against the product and rendered evidence.
